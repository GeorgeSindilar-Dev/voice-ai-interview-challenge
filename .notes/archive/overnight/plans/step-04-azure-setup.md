# Step 4: Azure Setup and Solution Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working workstation (Azure CLI, patched .NET SDK), an empty but building .NET solution, and every Azure resource created by **one** Bicep deployment with managed identities, role assignments and Key Vault secrets. No code is deployed yet.

**Architecture:** The owner signs in with `az login` (interactive; no keys in chat). Claude runs everything else in the owner's signed-in terminal session. `infra/main.bicep` creates the resources from [00-overview.md §4](00-overview.md). Secrets are generated by `scripts/set-secrets.ps1` straight into Key Vault and never printed. App settings reference them with `@Microsoft.KeyVault(...)`. Tables and the blob container's contents are created by the apps themselves; the container itself and its lifecycle policy are in Bicep.

**Tech Stack:** Azure CLI 2.x + Bicep, PowerShell 5.1, .NET 10 SDK.

**When:** Saturday morning, right after the questions. About 1.5 hours (most of it waiting for deployments).

- [ ] **Step 1: Write the script** (generates values and never prints them):

```powershell
<#
.SYNOPSIS
  Generates random secrets straight into Key Vault. Values are never printed.
  Re-running only creates missing secrets unless -Rotate is given.
#>
param(
    [Parameter(Mandatory)] [string] $KeyVaultName,
    [switch] $Rotate
)
$ErrorActionPreference = 'Stop'

function New-RandomSecret([int] $bytes = 32) {
    $buffer = New-Object byte[] $bytes
    [System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($buffer)
    # URL-safe base64 without padding
    [Convert]::ToBase64String($buffer).TrimEnd('=').Replace('+', '-').Replace('/', '_')
}

function New-PolicyPassword {
    # Satisfies the mock policy (12+ chars, upper, lower, digit): prefix + random
    'Init-' + (New-RandomSecret 12) + '9a'
}

$secrets = [ordered]@{
    'ServiceCredential'        = { New-RandomSecret 32 }
    'AccessCode'               = { (New-RandomSecret 9) }
    'MockUser0InboxPassword'   = { New-RandomSecret 12 }
    'MockUser0InitialPassword' = { New-PolicyPassword }
    'MockUser1InboxPassword'   = { New-RandomSecret 12 }
    'MockUser1InitialPassword' = { New-PolicyPassword }
    'MockUser2InboxPassword'   = { New-RandomSecret 12 }
    'MockUser2InitialPassword' = { New-PolicyPassword }
}

$existing = az keyvault secret list --vault-name $KeyVaultName --query "[].name" -o tsv
foreach ($name in $secrets.Keys) {
    if (-not $Rotate -and ($existing -contains $name)) { Write-Host "keep    $name"; continue }
    $value = & $secrets[$name]
    $tmp = New-TemporaryFile
    try {
        Set-Content -Path $tmp -Value $value -NoNewline -Encoding ascii
        az keyvault secret set --vault-name $KeyVaultName --name $name --file $tmp --encoding ascii --output none
    } finally { Remove-Item $tmp -Force }
    Write-Host "set     $name"
}
```

Using `--file` keeps the values off the command line, so they don't end up in shell history or the process list.
