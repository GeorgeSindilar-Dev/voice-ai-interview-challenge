# Audit 2: solution versus the specification (2026-10-04)

Scope: `solution/` at commit 41867c7 (branch `audit-after-testing`, same as `main`), compared with
`README.md`, `docs/mock-contract.md` and `contracts/submission.schema.json`. Read-only review: no
build, no tests run, no live call, no Azure access. Every finding comes from reading the current
code. Paths below are relative to `solution/src/VoiceReset/` unless they start with `solution/`.

Status words: **Met**, **Partly met**, **Not met**. Gap severity: **Critical** (blocks a valid
submission), **High** (the assessors will see it), **Medium**, **Low**.

Settled owner decisions, not raised again as gaps: phone through a third-party carrier instead of
ACS (agreed with the interviewer; not built yet); a meeting instead of the video; desktop only;
single instance; the mock is not hardened (junk requests, records kept forever); codes and links
readable in the mock's storage blob; no concurrency cap on calls. They still need a line in the
setup document's known limitations.
